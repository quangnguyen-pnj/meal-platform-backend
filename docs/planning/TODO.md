# Planning checklist

- [x] Ground: capture confirmed platform and deployment decisions.
- [x] Sketch: compare architecture and phased-delivery plans.
- [x] Agree: record the chosen plan and open decisions.
- [ ] Implement: execute the approved task sequence.
- [ ] Scrap: revisit the design if repeated implementation friction shows the plan is wrong.

## Architecture comparison checklist

- [x] Frame: define the planning artifacts and selection criteria.
- [x] Fan out: produce independent plan candidates.
- [x] Cross-judge: score candidates against the criteria.
- [x] Pick: select the simplest viable foundation.
- [x] Graft: merge useful details from rejected candidates.
- [x] Verify: ensure the final plan covers Phase 0 through Phase 2.
